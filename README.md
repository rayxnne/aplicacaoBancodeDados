Aplicação de Banco de Dados
Repositório para guardar as consultas realizadas com SQL no curso de Aplicação de Banco de Dados da FAT por meio do QualificaSP.

Durante o curso foram abordados assuntos como fundamentos de banco de dados (relacionais e não relacionais), MySQL e SQL Server com foco em criação de tabelas, comandos DML/DQL(manipulação e consulta de dados), JOINs e transações e Power BI para visualização de dados e construção de dashboards interativos.

Como projeto final realizei uma análise da alta evasão em cursos de TI no Brasil, utilizando dados do Censo da Educação Superior 2024 disponivéos no site do INEP(dados_evasaoTI.csv). O estudo identifica padrões de evasão, conclusão e matrícula em cursos de TI como Análise e Desenvolvimento de Sistemas, Ciência da Computação e Engenharia de Software, segmentados por curso, estado e região do Brasil.
Os dados foram estruturados em um banco relacional no MySQL(evasaoTI_modeloLogico.PNG), analisados via 14 consultas SQL(evasaoTI.scriptSQL) e visualizados em dashboards interativos no Power BI, cobrindo mais de 94 mil alunos matriculados e revelando que, dos 42 mil ingressantes em 2024, apenas 7 mil chegaram à conclusão.

🛠️ Ferramentas: MySQL · MySQL Workbench · Power BI · Dataset MEC/INEP 2024

Caso queira conferir mais informações da análise o arquivo Projeto_evasaoTI está disponível para leitura.
